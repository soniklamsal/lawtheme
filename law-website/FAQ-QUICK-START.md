# FAQ Section - Quick Start Guide

## 🚀 How to Edit FAQ Content

### Step 1: Access WordPress Customizer
1. Login to WordPress Dashboard
2. Go to **Appearance → Customize**
3. Click on **"FAQ Section"**

### Step 2: Manage FAQ Items

#### To Add a New FAQ:
1. Click the **"Add FAQ"** button
2. Enter the **Question** in the first field
3. Enter the **Answer** in the textarea below
4. Click **"Publish"** at the top

#### To Edit an Existing FAQ:
1. Find the FAQ you want to edit
2. Modify the Question or Answer text
3. Click **"Publish"** to save

#### To Remove an FAQ:
1. Find the FAQ you want to delete
2. Click the **"Remove"** button
3. Click **"Publish"** to save

### Step 3: Update Statistics

#### Cases Won:
- **Number Field:** Enter the number (e.g., 500)
- **Label Field:** Enter the text (e.g., "Cases Won")

#### Expert Attorneys:
- **Number Field:** Enter the number (e.g., 50)
- **Label Field:** Enter the text (e.g., "Expert Attorneys")

#### Practice Areas:
- **Number Field:** Enter the number (e.g., 25)
- **Label Field:** Enter the text (e.g., "Practice Areas")

### Step 4: Save Changes
Click the **"Publish"** button at the top of the Customizer

## 📍 Where to Find It

**WordPress Admin:**
```
Dashboard → Appearance → Customize → FAQ Section
```

**On Homepage:**
The FAQ section appears after the Testimonials section and before the WhatsApp button.

## 💡 Tips

1. **Keep Questions Clear:** Use simple, direct questions
2. **Keep Answers Concise:** 2-3 sentences work best
3. **Order Matters:** FAQs appear in the order you add them
4. **Statistics:** Use realistic numbers that reflect your firm
5. **Preview:** Use the Customizer preview to see changes before publishing
