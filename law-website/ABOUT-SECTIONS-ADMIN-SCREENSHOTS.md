## Color Coding

**Blue**: Primary actions (Publish, Update)  
**Green**: Success messages  
**Red**: Delete/Trash actions  
**Gray**: Secondary actions (Cancel, Draft)  

---

## Keyboard Shortcuts

- **Ctrl/Cmd + S**: Save draft
- **Ctrl/Cmd + Enter**: Publish/Update
- **Esc**: Close media uploader

---

## Tips for Best Experience

1. **Use Chrome or Firefox** for best compatibility
2. **Enable JavaScript** (required for media uploader)
3. **Clear cache** if changes don't appear
4. **Save frequently** while editing
5. **Preview before publishing** to check layout
